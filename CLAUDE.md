# Project Instructions

When not given a specific task, look in `tasks/todo/` for the next task file (ordered by filename number prefix). Before starting any task:

1. Read the task file
2. Present a summary to the user
3. Ask for confirmation or clarification before writing any code
4. Once approved, move the task file from `tasks/todo/` to `tasks/in-progress/`
5. Implement the task
6. When complete, move the task file from `tasks/in-progress/` to `tasks/done/`
7. Report completion and wait for the user before picking up the next task

Never start a task without user approval.
